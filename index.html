§00 MANIFESTO · 1 PAGE

CORE PRINCIPLE

Intentionality
over style.

Ardent is neither minimalist nor maximalist. It is intentional. Sparse when focus is required. Dense when information rewards exploration. The context determines the approach; the sin is arbitrariness.

A portfolio landing page may be quiet and restrained — a doorway. A dashboard or technical document may be dense and layered — a workbench. Both are correct if the decision is conscious.

The name reflects the character: intense, passionate, and burning — but controlled. Every decision is deliberate. Every element earns its place.

M-00 · framing This document is itself an Ardent artifact. Hairlines, mono metadata, harsh contrast, document container. Where it bends the rules (full-bleed type specimens, color grids), the purpose is to show the system, not to use it.
§01 TENETS · 8

The eight tenets.

Operating principles. Apply them in order when forces conflict — intentionality before transparency, transparency before timelessness, and so on. They are not aesthetic preferences; they are decision rules.

  1. 01

    Intentionality over style

    Every decision requires a reason. Aesthetic choices are functional responses to context. If you cannot articulate why an element exists, reconsider it.

  2. 02

    Transparency

    Expose state. Show the system. Don't hide the machine. Revealing inner workings builds trust and enables mastery.

  3. 03

    Timelessness

    Ignore trends. Design for permanence. If it would look wrong printed in 1978 or displayed in 2045, reconsider it.

  4. 04

    Precision

    Engineered, not decorated. Every element should feel built—considered, calibrated, placed. The aesthetic of control panels and datasheets.

  5. 05

    Functional density

    As complex as it needs to be. No more, no less. Information is not the enemy. Whitespace is structural; emptiness for its own sake is waste.

  6. 06

    Warmth through craft

    The human is visible in details. Precision is not cold. Care in typography, spacing, alignment—that is where warmth lives, not in whimsy.

  7. 07

    Performance is design

    Fast, lightweight, no bloat. The experience of speed is part of the aesthetic. A slow interface cannot be beautiful.

  8. 08

    Respect for users

    Don't infantilize. Users are capable adults. Be direct, clear, and explicit. Avoid soft language and false confirmation.

M-01 · resolved 0.1.3 Resolved — the order is now codified as philosophy.tenetOrder in tokens.json. When tenets conflict, intentionality trumps everything; respect-for-users is the floor.
§02 INFLUENCES · 3 SOURCES

Influences — 50 / 30 / 20.

Ardent synthesizes three sources in approximate proportion. Aesthetic from the first, architecture from the second, humanity from the third.

U.S. Graphics Co. 50%
IBM Carbon 30%
Recursive / brutalism 20%

U.S. Graphics Co.

50% · dominant aesthetic

The golden era of computing. Control panels, machine-readable typefaces, terminal interfaces, technical documentation. Where the look comes from.

  • Monospace for system text
  • Hairline borders, ruled dividers
  • Harsh contrast (near-black on off-white)
  • Flat, non-hierarchical surfaces
  • Color as semantic, never decoration
  • Dense information display

IBM Carbon

30% · architecture

Where USG is an aesthetic, Carbon is an architecture. The systematic rigor underneath the surface vocabulary.

  • Consistent spacing scale
  • Modular, composable components
  • Accessibility standards
  • Primitives → semantics → components
  • Professional doc practices

Recursive / brutalism

20% · warmth

Warmth within structure. Recursive's variable axes show that systematic design can still breathe. The soft end of brutalism.

  • Humanity within monospace
  • Playfulness without sacrifice of function
  • Ready for work, ready for play
  • Structural but approachable
M-02 · resolved 0.1.3 Resolved by restating the influence as philosophical: Recursive's lesson is warmth-within-structure, not a typeface substitution. The sans stack stays Inter → Helvetica Neue → Arial.

§06 CONTAINER · DEFAULT LAYOUT

The document on a desk.

Unless otherwise specified, pages use a centered container: 678 px white surface, gray.100 surround, hairline borders top and bottom. Mobile flattens to full-bleed. What you are reading right now is one.

§M ANNOTATIONS · 11 NOTES · ALL RESOLVED · v0.1.3

Notes from a junior.

Observations gathered while building this document. All addressed in tokens.json / AGENTS.md across v0.1.2 and v0.1.3. Kept here as a changelog and a record of why the spec looks the way it does.

M‑01
Order the tenets.resolved · 0.1.3 Added philosophy.tenetOrder to tokens.json — an explicit, ordered list (intentionality → transparency → timelessness → precision → functionalDensity → warmthThroughCraft → performance → respectForUsers). When tenets conflict, apply in order.
M‑03
Extend the size scale upward.resolved · 0.1.2 Added fontSize.6xl/7xl/8xl/9xl for cover-grade type, and split display into display + displayLg so it no longer shares the body scale.
M‑04
Resolve the amber orphan.resolved · 0.1.2 amber.500 removed. If a fifth accent is needed later, it ships as a full scale with a defined role.
M‑05

M‑06
Remove spacing duplicates.resolved · 0.1.2 Rewrote the spacing primitives so step number tracks size monotonically. space.4 is now 1rem, space.7 is 1.75rem, space.10 is 2.5rem, etc. No more synonyms.
M‑07
Delete vestigial radii.resolved · 0.1.2 borderRadius is stripped down to none, in line with the philosophy. Components reference it explicitly. The temptation to reach for a rounded corner now requires editing a primitive.
M‑08
Formalize the spec-document container.resolved · 0.1.2 Added spacing.page.maxWidthDoc (47.5rem / 760 px) alongside the reading container so spec sheets and changelogs widen honestly rather than ad hoc.
M‑09

M‑10
Add motion & focus tokens, even if zero.resolved · 0.1.2 motion.duration.* = 0ms and motion.easing.* = linear are canonical. "No animation" is a token value, not an implication. primitives.focus adds a shared focus ring (2px black, offset 0.125rem).
M‑11
Add a TUI / GUI surface note.resolved · 0.1.3 New top-level surfaces block in tokens.json describes how the vocabulary lands on each: TUI maps accents to ANSI 1/2/3/4 and hairlines to box-drawing glyphs (─ │ ┌ ┐ └ ┘); GUI uses the same hex values with platform-native rendering and no rounded corners.
